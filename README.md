# Tópicos Avançados em Sistemas para Internet

Repositório da disciplina **Tópicos Avançados em Sistemas para Internet:
Desenvolvimento de Software com Inteligência Artificial**, do curso de
Tecnologia em Sistemas para Internet (TSI).

## Carga horária e organização

- Carga horária total: **60 horas-aula**;
- Total: **80 aulas de 45 minutos**;
- Cada encontro: **2 aulas (90 minutos)**;
- Total: **40 encontros**;
- Organização avaliativa: **2 unidades de 20 encontros**;
- Stack: **TypeScript, Angular, NestJS, PostgreSQL/pgvector, Ollama e Docker**.

## Resultados esperados

Ao final, o estudante deverá ser capaz de integrar modelos locais a aplicações
Web, implementar saídas estruturadas, ferramentas, embeddings, busca vetorial,
RAG e workflows/agentes controlados, além de avaliar, observar e proteger essas
funcionalidades de IA.
