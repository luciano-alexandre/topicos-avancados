# Práticas de Laboratório

Os roteiros específicos podem ser criados a partir dos encontros e devem usar
um único projeto incremental sempre que isso reduzir trabalho de configuração.

## Padrão de entrega

1. objetivo e hipótese;
2. requisitos e versões do ambiente;
3. implementação;
4. casos de teste e dados de entrada;
5. resultados, métricas e limitações;
6. commit e instruções de reprodução.

Nunca versionar segredos, dados pessoais, prompts com informação confidencial
ou volumes locais do PostgreSQL/Ollama.
